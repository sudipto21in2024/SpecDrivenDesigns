# ADR-008 — OpenAPI multifile authorship + 150-line file-size governance

Status: Accepted (LOGI-0015 architect arm) · Date: 2026-09-26

## Context
`contracts/v1-openapi.yaml` reached 1074 lines / ~49KB. Every Architect arm
edited the same file (conflict hotspot), and agents' slice-first protocol
(`tools/contract/index.mjs`) had to regex-slice a monolith.

Separately: large generated/source files (>150 lines) hurt reviewability and
agent context budgets.

## Decision
1. **Authorship = `contracts/v1/*.yaml`** (17 fragments: `head/foot.yaml`,
   `paths/*.yaml` x7, `components/*.yaml` x2, `components/schemas/*.yaml` x7).
   Each fragment ≤150 lines (largest today: shipments paths 114, shipments
   schemas 94).
2. **Artifact = `contracts/v1-openapi.yaml`** (GENERATED header). Regenerated by
   zero-dep `node tools/contract/bundle.mjs` (verbatim concatenation in fixed
   key order); `--check` is the drift gate. Slicer, `generate:api`
   (`openapi-typescript`), backend tests, and Spectral keep reading the bundle
   unchanged — bundle output is byte-identical to the pre-split file plus the
   2-line header.
3. **Rigid 150-line rule for CODE** (`Docs/ProjectTechGuidence/07-coding-standards.md`):
   no `.cs`/`.ts`/`.tsx`/`.mjs`/`.cjs` or contract fragment may exceed 150 lines from
   creation onward, every arm/step — split/modularize first. Gate:
   `node tools/contract/check-size.mjs` (CI `File-size gate`; local `--staged`,
   `--files a,b`). **Markdown docs/specs/plans/journals and JSON (project-management,
   state, telemetry) are explicitly out of scope.** Further exemptions: generated bundle +
   `schema.d.ts`, EF Core `Migrations/**`, lockfiles, minified assets, binaries/DBs/logs.
   Legacy oversize code is grandfathered as a **shrink-only ratchet** in
   `tools/contract/size-baseline.json` (recorded count = ceiling; growth fails).
4. **Workflow** (`.github/workflows/ci.yml`): `bundle --check` → `check-size`
   → `spectral lint` (explicit `--ruleset`, unchanged semantics).

## Consequences
- Architect diffs become per-resource (`git diff contracts/v1/paths/shipments.yaml`).
- New error class: fragment key-order mistakes → caught by `bundle --check` +
  Spectral in CI.
- `PagedResponse` lives in `components/schemas/routes.yaml` tail (preserves
  original key order); do not "tidy" it into `common.yaml` without a bundle
  diff review.
- If a fragment approaches 150 lines (shipments paths 114 today), split it
  further (e.g. `shipments-queries.yaml`) — never grow past the limit.
